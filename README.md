## ◈ 05 — INSTALLATION & CONFIGURATION

### System Requirements

| Requirement | Version |
|:---|:---|
| Node.js | 20.19+ or 22.12+ |
| Package Manager | npm |
| Database Platform | Supabase |
| Code Editor | VS Code recommended |

### Step 01 — Clone Repository

```bash
git clone https://github.com/DeveloperSimu/Simu_Portfolio.git
```

### Step 02 — Enter Project Directory

```bash
cd Simu_Portfolio
```

### Step 03 — Install Dependencies

```bash
npm install
```

### Step 04 — Environment Configuration

Create `.env` in the root directory.

```env
VITE_SUPABASE_URL=https://YOUR_PROJECT_ID.supabase.co
VITE_SUPABASE_ANON_KEY=YOUR_PUBLISHABLE_OR_ANON_KEY
```

**Security Notice:** Use a Supabase publishable key or legacy anon key. Never expose a service-role or secret key in frontend code.

### Step 05 — Launch Development Environment

```bash
npm run dev
```

<details>
<summary><strong>◈ Production Build & Preview</strong></summary>

```bash
npm run build
npm run preview
```

The production-ready files are generated inside the `dist/` directory.

</details>

## ◈ 06 — DATABASE & SUPABASE

Database migrations are maintained inside:

```text
supabase/migrations/
```

Execute the migrations in timestamp order through the Supabase SQL Editor.

| Migration | Purpose |
|:---|:---|
| `20261031160053_create_contact_messages.sql` | Contact submissions |
| `20261031161136_create_site_visits_counter.sql` | Website visit counter |
| `20261031161142_create_blog_posts.sql` | Blog publishing system |
| `20261031161846_create_newsletter_subscribers.sql` | Newsletter subscriptions |

### Publishing New Blog Articles

1. Open the Supabase Dashboard.
2. Navigate to **Table Editor → blog_posts**.
3. Insert a new article.
4. Provide title, unique slug, excerpt, category, tags and body.
5. Set `published` to `true`.
6. Refresh the `/#blogs` page.

Curated blog content is maintained in:

```text
src/data/blogPosts.ts
```

## ◈ 08 — PRODUCTION DEPLOYMENT

The application can be deployed through a static hosting provider.

The **Explore all blogs** link uses `/#blogs`, so it works on static hosts without a rewrite rule. Direct `/blogs` URLs require an SPA fallback.

### Deployment Workflow

```text
SOURCE CODE
     │
     ▼
DEPENDENCY INSTALLATION
     │
     ▼
ENVIRONMENT CONFIGURATION
     │
     ▼
PRODUCTION BUILD
     │
     ▼
SUPABASE CONNECTION
     │
     ▼
STATIC HOSTING
     │
     ▼
LIVE PORTFOLIO
```

### Deployment Checklist

- [ ] Configure production environment variables.
- [ ] Apply all Supabase migrations.
- [ ] Execute `npm run build`.
- [ ] Deploy the generated `dist/` directory.
- [ ] Verify the blog archive at `/#blogs`.
- [ ] Verify database connectivity.
- [ ] Test contact and newsletter forms.
- [ ] Check desktop and mobile responsiveness.

---

## ◈ 09 — SECURITY & ENGINEERING STANDARDS

Security is an essential part of the application architecture.

- Environment credentials must remain private.
- Never commit `.env` files.
- Never expose Supabase service-role keys.
- Use publishable keys for browser-side operations.
- Apply and review Row Level Security policies.
- Validate database permissions.
- Keep production secrets outside the repository.
